# Changelog

All notable changes to shopifyql-skill are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.5.0] - 2026-05-25

### Added
- Cross-platform support documentation (Cursor, Codex CLI, Gemini CLI)
- `examples/` directory with 9 ready-to-use ShopifyQL queries
- `.github/` community files (CONTRIBUTING, SECURITY, issue templates)
- Star history chart in README
- Comparison table showing benefits vs alternatives
- Persona-based value propositions

### Changed
- README restructured with value proposition first, syntax docs second
- Expanded plugin.json keywords (8 to 20)

## [1.4.0] - 2026-05-01

### Added
- `/shopifyql-setup` interactive credential wizard
- `shopifyql-executor` agent for query execution

## [1.3.0] - 2026-04-15

### Added
- Python execution script with SDK integration
- Rate limit handling with 60s backoff
- CSV export for large result sets

## [1.2.0] - 2026-04-01

### Added

## [1.1.0] - 2026-03-15

## [1.0.0] - 2026-03-01
